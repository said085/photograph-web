# Masai Mara Photography

## Author
Said Juba
## Description
This is a beginner photography website about the Masai Mara
National Reserve in Kenya. It showcases wildlife, landscapes
and the beauty of African nature.
## Features
- Introduction to Masai Mara
- Favourite wildlife photo gallery
- Photographer biography
- Contact form
- Responsive layout
- Custom CSS design
## Technologies
- HTML5
- CSS3
## Setup Instructions
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Make sure index.html and style.css are in the same folder.
4. Open index.html using Live Server.
5. Connect to the internet to load the images.
